# 功能需求规格

## 项目名称
DeepSeek Monitor — DeepSeek API 余额 & Token 用量监控桌面应用

## 目标用户
Windows 用户，非技术背景，拥有 DeepSeek API Key

## 功能清单

### F1. 余额监控
- 显示总余额（¥），大字体突出
- 显示本月累计消费
- 分开展示赠送余额 / 充值余额
- 显示上次刷新时间
- 支持手动刷新 + 定时自动刷新（5/10/30/60分钟）

### F2. Token 用量（按模型分开）
- V4 Flash：Token 消耗量 + 费用
- V4 Pro：Token 消耗量 + 费用
- 输入 / 输出 Token 分开（如有数据）

### F3. 消耗趋势图表
- 近 7 天柱状图（每天总费用）
- 双折线图（V4 Flash vs V4 Pro）
- 鼠标悬浮显示当天详情

### F4. 数据导入导出
- 拖拽 CSV 导入
- 数据导出为 CSV
- 记录导入时间

### F5. API 自动获取
- GET /user/balance 查询余额
- GET /v1/usage 查询用量

### F6. 本地缓存
- SQLite 存储历史数据
- 启动时加载缓存，不白屏
- 后台拉取最新数据

### F7. 开机自启
- 支持注册开机启动
- 最小化到系统托盘
- 可在设置中开关

### F8. 余额不足提醒
- 自定义告警阈值（默认 ¥10.00）
- 系统通知 + 提示音
- 防重复提醒

### F9. 数据安全
- API Key AES 加密存储
- 不上传任何外部服务器
- 所有数据仅存本地
