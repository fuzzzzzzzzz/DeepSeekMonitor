## 设计元素

### 卡片面板 (Comic Panel)
- 粗边框 2-3px，漫画分镜风格
- `border-radius: 12-16px`
- 轻微 `box-shadow` 增加立体感
- 半透明深色背景

### 漫画装饰
- 网点图案（halftone dots）：CSS `radial-gradient` 实现
- 星光/钻石装饰：CSS 伪元素 + Unicode 符号（✦ ⬥ ◆ ★）
- 速度线/集中线：CSS 条纹背景
- 气泡对话框风格提示

### 字体层级
- **特大数字**（余额）：36-48px，`font-weight: 800`
- **大数字**（模型用量）：24-28px，`font-weight: 700`
- **标题**：18-20px，`font-weight: 700`
- **正文**：14px，`font-weight: 400`
- **标签**：12px，`font-weight: 500`
- 字体族：`'Segoe UI', 'Microsoft YaHei', sans-serif`

### 底部导航栏
- 4 个 Tab：首页 🏠 / 趋势 📊 / 导入 📥 / 设置 ⚙️
- 固定在窗口底部
- 当前 Tab 高亮（强调色边框 + 发光效果）
